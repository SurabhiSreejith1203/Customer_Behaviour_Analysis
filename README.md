
# Customer Behaviour Analysis — End-to-End Data Analytics Project

## Project Overview

This project focuses on analyzing customer shopping behaviour to uncover purchasing patterns, understand customer preferences, and derive insights that can support data-driven business decisions.

Using Python, PostgreSQL, and Power BI, the project follows a data analytics workflow involving data cleaning, feature engineering, SQL-based business analysis, and interactive dashboard development.

## Objectives

- Analyze customer spending patterns across gender and age groups.
- Identify products with the highest average customer ratings.
- Examine the relationship between discounts and purchase amounts.
- Compare spending behaviour between subscribed and non-subscribed customers.
- Segment customers into New, Returning, and Loyal categories.
- Identify the most frequently purchased products within each category.
- Analyze purchasing frequency and customer preferences.
- Present customer insights through a Power BI dashboard.

## Dataset

The project uses a customer shopping behaviour dataset containing information about customer demographics, purchases, product categories, discounts, subscriptions, shipping methods, review ratings, and previous purchases.

Key attributes include:

- Customer ID
- Age and Gender
- Item Purchased and Category
- Purchase Amount
- Review Rating
- Discount Applied
- Subscription Status
- Shipping Type
- Frequency of Purchases
- Previous Purchases

## Project Workflow

**Raw Dataset → Python Data Cleaning → PostgreSQL Analysis → Power BI Dashboard**

### 1. Python Analysis

Used Python and Pandas to inspect, clean, and transform the raw customer shopping dataset.

Key tasks performed:

- Explored dataset structure, data types, summary statistics, and missing values.
- Handled missing review ratings using category-wise median imputation.
- Standardized column names and renamed columns for consistency.
- Created age groups using quartile-based segmentation.
- Converted purchase frequency categories into approximate day intervals.
- Checked consistency between discount and promotional-code indicators.
- Removed redundant columns to prepare the dataset for further analysis.

### 2. SQL Analysis — PostgreSQL

Used PostgreSQL to answer business questions and analyze customer purchasing behaviour.

Key business questions explored:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent more than the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare across shipping methods?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of purchases with discounts?
7. How can customers be segmented into New, Returning, and Loyal groups?
8. What are the top three most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

**SQL concepts applied:** Aggregate functions, `GROUP BY`, subqueries, `CASE` statements, Common Table Expressions (CTEs), window functions, `ROW_NUMBER()`, and conditional aggregation.

### 3. Power BI Dashboard

Developed a Power BI dashboard to present customer shopping behaviour and make the analysis easier to interpret.

The dashboard complements the Python and SQL analysis by providing a visual overview of customer spending, product performance, and purchasing patterns.
